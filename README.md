# 招投标保证金退还管理系统

全栈 Web 应用，管理招投标流程中的保证金缴纳、中标结果确认、退还申请审批及付款凭证归档。

## 功能模块

- **项目标段管理** — 创建和管理项目标段，跟踪开标/定标/签约状态
- **补充材料管理** — 按标段管理补充材料，支持提交、审核、拒绝全流程
- **保证金流水** — 录入投标方保证金缴纳记录
- **中标结果** — 录入中标人信息，跟踪合同签约状态
- **退还申请** — 发起保证金退还，系统自动校验业务规则
- **付款凭证** — 对已审批退还登记付款凭证

## 业务规则

1. **未开标项目不能退还** — 标段状态为"未开标"时，任何保证金不可发起退还
2. **中标人未签合同不能退保证金** — 已定标但中标人未签合同时，中标人的保证金不可退还
3. **补充材料未全部通过前不能退还** — 标段存在未审核通过的补充材料时，不可发起保证金退还

## 补充材料使用指南

### 功能入口
在「项目标段管理」页面，每个标段操作列新增「补充材料」按钮，点击即可进入该标段的补充材料管理界面。

### 状态流转
补充材料包含以下状态，形成完整的审核流程：

- **待提交**：材料刚创建，可编辑、提交或删除
- **已提交**：材料已提交审核，可通过或拒绝
- **已通过**：材料审核通过，归档留存
- **已拒绝**：材料被拒绝，显示拒绝原因

### 操作说明
1. **新增材料**：填写材料名称、类型、描述及可选的文件链接
2. **提交审核**：材料编辑完成后提交进入审核流程
3. **审核通过**：管理员确认材料符合要求
4. **审核拒绝**：材料不符合要求，填写拒绝原因
5. **删除材料**：仅待提交状态的材料可删除

## 技术栈

- 前端：React 18 + TypeScript + Tailwind CSS + Vite + Zustand
- 后端：Express 4 + TypeScript
- 数据库：SQLite (sql.js)

## 本地开发

```bash
npm install
npm run dev
```

前端 http://localhost:5173，后端 API http://localhost:3001

## Docker 部署

```bash
docker compose up --build
```

应用启动在 http://localhost:3000

## 冒烟测试

```bash
bash scripts/smoke.sh
```

验证核心业务规则：对未开标标段发起退还并确认系统拒绝。
